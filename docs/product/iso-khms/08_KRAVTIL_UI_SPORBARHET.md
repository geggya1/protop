# 08 – Kobling: funksjon → skjema → graf → ISO-kravområde → evidens

Dette er en **funksjonell matrise**. Kravklausuler og normativ dekning skal fagverifiseres mot lisensiert standardtekst for hver aktuell utgave. Matrisen er en spesifikasjon for beviskobling, ikke ferdig sertifiseringsverifikasjon.

## Ansvar for innhold og kvalitet

- **Product owner:** prioritert funksjonalitet, UX, brukervennlighet og integrasjon.
- **Kvalitets-/HMS-fagansvarlig:** faglig riktig struktur, rutiner og vurderinger for reelle virksomheter.
- **Sertifiserings-/ISO-ekspert:** korrekt kravtolkning, standardversjon, klausulkobling og normative krav; behov for tilgang til lovlige standardtekster.
- **Juridisk personvern-/HMS-rådgiver:** relevante norske krav, behandling av sensitive opplysninger, lovpliktig rapportering og dokumentasjon.
- **Teknisk ansvarlig:** datamodell, isolasjon, autorisasjon, skjemaversjoner, sikre integrasjoner og tester.
