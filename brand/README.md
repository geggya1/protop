# ProTop-logoer

Legg nye filer fra neste leveranse i denne mappen, og registrer dem i `manifest.json`. Siden leser stier og farger derfra.

Primær lås på lys bakgrunn: `ProTop_logo_primary_transparent.png`.
Hvit lås på mørk bakgrunn: `ProTop_logo_white_transparent.png`.
Favicon og appikon: `ProTop_favicon.ico` og `ProTop_icon_*.png`.

Farger fra merkevarearket: marineblå `#07274C`, digital blå `#1099F4`, hvit `#FFFFFF`.

`source/` inneholder original-PDF og pakkenotatet. PDF-ene er raster (ReportLab), ikke Bézier-kurver, så grensesnittet bruker PNG. `ProTop_logo_primary.svg` og `ProTop_symbol.svg` sto i pakkenotatet, men fulgte ikke med denne leveransen.

Symbolet i kildefilene har en liten «Digi»-påskrift. Produktnavnet er ProTop. Ikke bytt ut primærlåsen med Digi-ordmerket.
